# Data

No data or results are distributed with this repository. Downloads go to `data/`, everything the code writes to
`results/` (both are ignored by git).

## Simulated data

Generated by `simulation/` (`scripts/generate_data.sh`, `scripts/generate_complex_data.sh`): a pool of 50,000 cells and
8,000 genes in nine groups from Splatter (R), split into a single-cell reference and the cells of the spots, spots of
eight cells on a spatial layout, a perturbation of one group, and an optional gene-wise capture efficiency of the ST.
Data seeds 21-30 are the final evaluation and 11-13 the hyperparameter comparison.

## Public data

| data set | source | download |
|---|---|---|
| mouse liver, acetaminophen overdose | GEO GSE223558 (snRNA-seq), GSE223560 (Visium) | `realdata/liver/fetch.sh` -> `data/liver_apap/download/` |
| mouse kidney, ischemia-reperfusion | GEO GSE139107 (snRNA-seq), GSE269622 (Visium) | `realdata/kidney/fetch.sh` -> `data/kidney_iri/download/`, `data/kidney_iri/visium/` |

The fetch scripts download the supplementary files of the GEO series and unpack them into the layout that
`realdata/*/make_scenario.py` reads. The use of these data sets is subject to the terms of their sources.

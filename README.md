# Perturbed Spatial Omics

Code for inferring perturbation responses in spatial transcriptomics via optimal transport map transfer. A perturbation
map is learned between control and perturbed single-cell RNA-seq with CellOT and transferred to pseudo-cells that a
spot model builds for every spot of a control spatial transcriptomics (ST) section; decoding the transported
pseudo-cells gives the predicted perturbed ST.

The repository contains the method as a Python package, the pipeline that runs it (and the comparison method
SIMO+CellOT) on simulated and public data, the simulation generator, and the Docker environment. No data or results
are distributed: simulated data are generated by the code and public data are downloaded from GEO.

## Layout

```text
src/perturbed_spatial_omics/  the method: spot model (stmix.py), autoencoder (autoencoder.py), CellOT transport (transport.py)
src/cellot/                   part of CellOT used by the package (BSD 3-Clause, see src/cellot/NOTICE.md)
pipeline/                     one run of the method on one condition: data preparation, training, prediction, evaluation
simulation/                   simulated data: Splatter cell pool (R), scenarios, complex spatial structure
scripts/                      job scripts for the simulations and the run lists of the reported conditions
realdata/                     mouse liver (acetaminophen) and kidney (ischemia-reperfusion) injury: download, run, summary
environment/                  Dockerfiles, Compose file, package versions, environment check
docs/                         data, workflows, and which code produces which result
```

## Quick start

Requirements: Docker with Compose v2. Everything runs on a CPU; an NVIDIA GPU is optional (`PYSVC=pygpu`).

```bash
docker compose -f environment/compose.yaml --profile simo --profile r build py simo r
docker compose -f environment/compose.yaml run --rm py python environment/smoke_test.py

scripts/generate_data.sh evaluation 21                 # simulated data of data seed 21
scripts/run_condition.sh capture 21 main none          # unpaired group scenario: train, predict, evaluate
cat results/conditions/capture/seed_21/main_cap_none/eval.csv
```

`docs/WORKFLOWS.md` gives the commands for every workflow, `docs/DATA.md` the data, and `docs/CODE_MAP.md` which
workflow and script produce each reported result.

## Using the method on other data

`pipeline/run_condition.py` takes a directory with three AnnData files of raw counts and the same genes in the same
order: `sc_ctrl_raw.h5ad` and `sc_stim_raw.h5ad` (control and perturbed single-cell reference) and `st_ctrl_raw.h5ad`
(control spots with coordinates in `.obsm["spatial"]`). `realdata/*/make_scenario.py` shows how such a directory is
built from public data, and `realdata/*/run.sh` how the stages are called (`--auto-dims` takes the numbers of genes and
spots from the input; `--skip-qc` keeps the cells as given).

```bash
python pipeline/run_condition.py --scenario-dir <dir> --output-root <out> --name <name> --seed 1 --auto-dims --skip-qc --stage stmix
python pipeline/run_condition.py --scenario-dir <dir> --output-root <out> --name <name> --seed 1 --auto-dims --skip-qc --stage full
```

The predicted perturbed ST is written to `<out>/predictions/<name>_proposed_stim_raw_G8000_modelseed1.h5ad` (the
`G8000` label is part of the file names whatever the number of genes).
